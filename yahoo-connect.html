Yahoo Fantasy Connection

Yahoo provides a Fantasy Sports REST API, but private leagues require OAuth. The client secret and refresh token must remain on a server; they cannot be safely stored in this public GitHub Pages dashboard.

  1. Create a Yahoo Developer application with Fantasy Sports read access.
  2. Deploy the repository's server/yahoo_oauth.py adapter on a private HTTPS server.
  3. Add YAHOO_CLIENT_ID, YAHOO_CLIENT_SECRET, YAHOO_REDIRECT_URI, and YAHOO_SESSION_SECRET to that server.
  4. Enter the deployed server URL below. The dashboard stores it in this browser until removed.
